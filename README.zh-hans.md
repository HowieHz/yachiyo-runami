# 八千代的链接小角落

[EN](./README.md) | **ZH**

来访问吧：[yachiyo-runami.com](https://yachiyo-runami.com)～♪

这是一个收集八千代相关官方站与同人站的静态链接小角落，欢迎慢慢逛～♪

## 关于这个小角落

- 直接用浏览器打开 `index.html` 即可，不需要构建或服务器☆
- 支持中文、日文、韩文和英文。
- 分享特定语言版本时，可以在 URL 后加上 `?lang=`：

```text
?lang=zh
?lang=ja
?lang=ko
?lang=en
```

切换语言时，页面标题、描述、Open Graph 元数据、canonical URL 和 `lang` 属性也会同步更新。

## 更新页面

需要 Node.js 20 或更高版本：

```bash
npm install
npm run fmt
npm run check
```

`npm run check` 会检查 Prettier 格式和 HTMLHint 规则。
