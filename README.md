# Yachiyo's Link Corner

**EN** | [ZH](./README.zh-hans.md)

Come visit: [yachiyo-runami.com](https://yachiyo-runami.com)～♪

A small, static link corner for official and fan websites related to ☽Yachiyo☾. Please take your time looking around～♪

## About This Little Corner

- Open `index.html` directly in a browser. No build step or server is needed☆
- Chinese, Japanese, Korean, and English are available.
- Add `?lang=` to a URL when sharing a specific language version.

```text
?lang=zh
?lang=ja
?lang=ko
?lang=en
```

The selected language updates the page title, description, Open Graph metadata, canonical URL, and `lang` attribute, too.

## Updating The Site

Node.js 20 or later is required.

```bash
npm install
npm run fmt
npm run check
```

`npm run check` verifies Prettier formatting and HTMLHint rules.

## Deployment

This little corner is currently served through GitHub Pages☆
